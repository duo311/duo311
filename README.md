## 📊 Featured Project

### 🤖 AI Resume Screener
> *My current flagship project — where I put LLMs to real-world use*

An intelligent resume screening tool that uses Large Language Models to **analyze resumes against job descriptions** — automating the first-pass hiring filter with AI.

**What it does:**
- 📄 Parses and understands resume content with LLMs
- 🔍 Compares candidate profiles against job requirements
- 📊 Scores and ranks resumes based on relevance
- ⚡ Powered by OpenAI / Groq API for fast, accurate analysis

**Built with:** Python • OpenAI/Groq API • Prompt Engineering
